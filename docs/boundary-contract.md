# Three-layer memory boundary

## Hermes internal memory

Authority: compact canonical facts, exact paths and identifiers, hard operating boundaries, and provider quirks.

Excluded: incidents, raw evidence, procedures, project diaries, and inferred preferences.

## Honcho

Authority: human preferences, collaboration patterns, conversational continuity, and curated conclusions.

Excluded: secrets, raw operational logs, alert payloads, deployment history, and bulk Obsidian imports.

## Memoria

Authority: append-only operational evidence, dated decisions, incidents, source snapshots, graph relations, and task-scoped citations.

Excluded: credentials, automatic identity inference, and automatic writes to Hermes or Honcho.

## Resolution order

1. A live check determines current operational truth.
2. Explicit Hermes canonical memory determines stable operating constraints.
3. Memoria supplies historical evidence and provenance.
4. Honcho supplies human context, not system truth.

Promotion from Memoria is never implied by retrieval. It requires a target profile, conflict key, precondition, evidence reference, explicit review, external application, and recorded read-back verification.
